# Role Binding Registry

`PROJECT_ID`、`ROLE_ID`、`THREAD_ID`、`TASK_ID`、`EXECUTION_ID` 和 `OUTER_TASK_ID` 是不同字段。显示名只用于界面，不是通信地址；`OUTER_TASK_ID` 永远不是线程目标。最初调用 Skill 的当前对话已经是唯一 `CORE_ARCHITECT`，其生命周期不是线程创建。

平台必须提供真实项目、线程身份和实际消息工具使用的通信目标句柄。`THREAD_ID` 与 `COMMUNICATION_TARGET_HANDLE` 是两个独立字段；只有平台工具契约明确证明二者相同，才可以记录相同值。若当前线程身份不可可靠取得，保留 `CURRENT_CONTEXT / REUSE_CURRENT / BINDING_BLOCKED` 并报告 `CURRENT_THREAD_ID_UNAVAILABLE / CAPABILITY GAP`，绝不能创建替代 Core Architect。Mission Planner 和 Build Executor 只有在原生创建返回真实 `threadId` 后才能改为 `BOUND`。
