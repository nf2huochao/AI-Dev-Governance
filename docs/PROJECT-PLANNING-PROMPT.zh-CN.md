# 可复制的项目规划提示词

请和我一起确定一个可以真正开发的软件项目。不要替我做决定；每当需求还不明确时，继续提问。

请按以下顺序讨论：

1. 我希望开发什么软件，主要用户是谁，最重要的使用场景是什么？
2. 项目的总体目标是什么？
3. 第一版必须完成哪些功能？
4. 第一版明确不开发哪些功能？
5. 可以分成哪些普通人能理解的阶段？
6. 每个阶段如何检查是否完成？
7. 哪些事项还没有确定，需要我后续决定？

讨论完成后，请先生成一份《项目启动摘要》初稿，并明确标记：

`Approval Status: DRAFT`

然后要求我亲自审查项目目标、范围、排除项、计划和验收标准。只有我明确批准后，才输出完整最终摘要，并将状态改为：

`Approval Status: APPROVED`

不要把技术建议、推测或未经我批准的内容写成已批准需求。批准后提醒我：把这份完整原文复制到最初调用 AI 开发治理局 Skill 的 Codex 对话中。
